# memory-to-repo

Скилл для Claude Code: вместе с тобой разбирает локальную память агента и переносит то, что в ней ценно, туда, где это видят все.

## Зачем

Claude Code по умолчанию сам копит заметки в `~/.claude/projects/*/memory/`. Отсюда три проблемы:

- **Агенты в команде работают по-разному.** У каждого копятся свои правила, которых нет у коллег. Новый человек получает агента «хуже», хорошие практики не расходятся по команде.
- **Копии устаревают.** Правило в репозитории поменяли, а копия в чьей-то памяти осталась старой.
- **Оглавление памяти занимает контекст в начале каждой сессии.** Чем больше записей, тем больше токенов уходит, прежде чем агент начнёт работать.

Правильное место для знаний о проекте — `CLAUDE.md` / `AGENTS.md` / `docs` в репозитории. Для знаний о тебе — твой `~/.claude/CLAUDE.md`.

## Установка

В Claude Code:

```
/plugin marketplace add Egorrko/memory-to-repo
/plugin install memory-to-repo@memory-to-repo
```

Нужен `python3`. Работает на Linux, macOS и Windows.

## Запуск

Из домашней папки, чтобы агенту были видны все проекты:

```
cd ~
claude
/memory-to-repo:memory-to-repo
```

Агент сначала покажет твои цифры (сколько записей, в каких проектах, сколько токенов уходит на оглавления), предложит открыть страницу со всем, что он о тебе помнит, и спросит, начинать ли. Дальше по шагу на проект: «Шаг 3/9 · ~/work/api · 12 записей». На каждом шаге одна таблица и обычно один вопрос: «принять всё как предложено» или «пройтись по спорным». Записи раскладываются так:

| Категория | Куда |
|---|---|
| уже есть в репозитории | никуда, только в архив |
| знание для всей команды | коммит в ветку `memory-to-repo` репозитория |
| про тебя в любом проекте | `~/.claude/CLAUDE.md` |
| про тебя в этом проекте | `CLAUDE.local.md` (не попадает в git) |
| устаревшие статусы и история | никуда, только в архив |

В конце память выключается (`"autoMemoryEnabled": false` в `~/.claude/settings.json`), а в `~/.claude/CLAUDE.md` появляется правило: новое знание агент предлагает правкой в репозиторий.

## Страница «что Claude о тебе помнит»

`memview.py` собирает одну HTML-страницу со всеми записями памяти, включая уже разобранные, и открывает её в браузере. Работает офлайн, ничего никуда не отправляет. Скилл предлагает её в начале разбора, а открыть можно и без него:

```
python3 ~/.claude/plugins/cache/memory-to-repo/memory-to-repo/*/skills/memory-to-repo/memview.py
```

На странице видно:
- когда каждая запись появилась и менялась;
- её полный текст;
- строку в `MEMORY.md`, то есть то, что агент видит в начале каждой сессии;
- в какой сессии запись появилась (есть кнопка `claude --resume`);
- связи между записями.

Записи можно отметить «оставить / в репо / удалить» и кнопкой скопировать отметки в разбор. Флаг `--watch` пересобирает страницу при каждом изменении памяти, `--out FILE` сохраняет её в другое место.

## Что скилл не делает

- **Ничего не удаляет.** Разобранная память переезжает в `~/.claude/memory-archive/`.
- **Не пушит.** Ветку `memory-to-repo` смотришь и отправляешь сам или открываешь PR.
- **Не трогает твой рабочий checkout.** Коммиты делаются в отдельном `git worktree` от основной ветки.

Разбор можно прервать: прогресс лежит в `~/.claude/memory-archive/progress.json`. Следующий запуск продолжит с того же места.
